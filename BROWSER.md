# Браузер для слабого ноутбука на antiX

**Русский** | [English](BROWSER.en.md)

Совсем лёгкого браузера, который нормально открывает современные сайты, не существует:
YouTube, почта и соцсети сами по себе съедают много памяти. Поэтому лучший вариант —
обычный браузер плюс правильные настройки.

## Сколько у вас памяти

```bash
free -h
```

- **около 4 ГБ** — берите Firefox ESR с настройками ниже;
- **8 ГБ и больше** — подойдёт любой браузер, хоть Chrome.

## Рекомендация: Firefox ESR

```bash
sudo apt install firefox-esr
```

Обычно расходует меньше памяти, чем Chrome, и хорошо поддаётся настройке.
Сделайте три вещи:

1. **Установите расширение uBlock Origin.** Оно блокирует рекламу и трекеры, а это
   заметная доля расхода памяти на многих сайтах.
2. **Уменьшите число процессов.** Наберите в адресной строке `about:config`, найдите
   `dom.ipc.processCount` и поставьте `2` (по умолчанию 8). Каждый процесс ест память,
   а на слабом ноутбуке двух хватает.
3. **Держите поменьше вкладок.** Firefox сам выгружает старые вкладки, когда память
   кончается, но 5–10 открытых вкладок всё равно лучше, чем 30.

## Если привычнее Chrome

Включите **Настройки → Производительность → Экономия памяти**. Тогда неактивные вкладки
будут засыпать. Без этой настройки Chrome на слабой машине тяжелее Firefox.

## Совсем лёгкие браузеры

**Falkon**, **NetSurf**, **Dillo** почти не тратят память, но многие современные сайты
(YouTube, Госуслуги, банки) в них работают плохо или не работают вовсе.
Подойдут разве что для чтения простых страниц.
