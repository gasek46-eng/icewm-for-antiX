# Orchard — antiX в стиле macOS

**Русский** | [English](README.en.md)

![Светлый режим](preview-light.png)
![Тёмный режим](preview-dark.png)

Новая цельная тема для antiX с IceWM: окна, верхняя панель, док, обои, поиск, уведомления,
светлый и тёмный режим. Без логотипов Apple, вся графика нарисована с нуля.

## Что внутри

- **Окна**: кнопки-«светофор» слева (при наведении ×, −, ⤢), заголовок по центру, тени, скругления.
- **Верхняя панель** как строка меню: меню-листок слева, трей и часы «Вс 11 окт 15:40» справа.
- **Док Plank** внизу с увеличением значков; открытые программы видны в доке.
- **Поиск программ** (Super+Пробел) и **уведомления** справа сверху.
- **Светлый и тёмный режим** со своими обоями; переключение Super+Shift+D.
- **Настройки Orchard** (Super+,): режим, обои, размер и автоскрытие дока, эффекты, яркость.
- **Шрифты** Inter и JetBrains Mono с чётким сглаживанием.
- Темы программ, иконки и курсоры **WhiteSur** (скачиваются при установке).

## Установка

```bash
cd ~/Загрузки
git clone https://github.com/gasek46-eng/icewm-for-antix
bash icewm-for-antix/orchard/install.sh
```

Без `sudo`, пароль спросит сам. Нужен интернет. Без интернета:
`bash install.sh --no-whitesur` (будут стандартные темы программ).
После установки **выйдите из сеанса и войдите снова**.

Установщик сохраняет резервную копию, отключает Conky и старые запуски picom/plank
(например, от `antix-macos-look`), чтобы ничего не дублировалось.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Super+Пробел | поиск программ |
| Super+, | Настройки Orchard |
| Super+Shift+D | светлый ↔ тёмный режим |
| Super+Q / Super+M | закрыть / свернуть окно |
| Super+E / Super+T | файлы / терминал |
| Super+Shift+3 / 4, Print | снимок экрана / области |
| Super+L | блокировка экрана |
| Alt+Tab | переключение окон |

Из терминала: `orchard-ctl mode dark`, `orchard-ctl wallpaper ~/картинка.jpg`,
`orchard-ctl dock size 56`, `orchard-ctl effects off`.

## Удаление

```bash
bash ~/.local/share/orchard/install.sh --remove
```

Возвращает все изменённые файлы из резервной копии.

## Проверено

Установка, светлый/тёмный режим, док, уведомления и удаление проверены на виртуальном
экране (IceWM 3.4, picom, Plank). На реальном antiX 26 — проверьте и сообщите, если что-то не так.
Графику можно перерисовать: `python3 tools/build-assets.py`.
