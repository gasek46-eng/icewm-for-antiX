# IceWM for antiX

Исправления для тем IceWM в стиле macOS на antiX Linux.

## fix-icewm-buttons.sh — чёрная полоса под кнопками окна

### Симптом

В заголовке окна слева кнопки-«светофор» (закрыть / свернуть / развернуть)
срезаны наполовину, а под ними чёрный прямоугольник. Он появляется на всех окнах
и перемещается вместе с окном. Если выключить picom (`pkill picom`), полоса остаётся.

### Причина

В IceWM каждая картинка кнопки заголовка (`closeA.xpm`, `maximizeA.xpm`,
`minimizeA.xpm` и т.д.) должна содержать **два состояния одно над другим**:
обычное сверху и нажатое снизу. То есть картинка должна быть **вдвое выше** кнопки
(см. [IceWM Theme Creation Howto](https://ice-wm.org/themes/)).

Если в теме картинки одинарные (например, 20×28 при `TitleBarHeight=28`), IceWM
показывает только их верхнюю половину, а остаток заголовка остаётся чёрным.

### Что делает скрипт

1. Находит текущую тему IceWM по файлу `~/.icewm/theme`, либо берёт папку темы из аргумента.
2. Сохраняет резервную копию картинок в `~/knopki-backup/<дата>/`.
3. Удваивает по высоте **только одинарные** картинки кнопок. Повторный запуск
   безопасен: уже исправленные файлы не трогаются.
4. Исправляет копию темы в наборе `~/Загрузки/antix-macos-look`, если он есть,
   чтобы повторный `install.sh` не вернул проблему.
5. Перезапускает IceWM и picom.

Если ImageMagick не установлен, скрипт поставит его сам (спросит пароль).

### Установка и запуск

```bash
mkdir -p ~/scripts
curl -L -o ~/scripts/fix-icewm-buttons.sh \
  https://raw.githubusercontent.com/gasek46-eng/icewm-for-antix/main/fix-icewm-buttons.sh
bash ~/scripts/fix-icewm-buttons.sh
```

Запускайте **без `sudo`**: тема лежит в домашней папке пользователя.

Для другой темы укажите её папку:

```bash
bash ~/scripts/fix-icewm-buttons.sh ~/.icewm/themes/ИМЯ-ТЕМЫ
```

### Откат

Команда отката печатается в конце работы скрипта. В общем виде:

```bash
cp ~/knopki-backup/<дата>/*.xpm ~/.icewm/themes/<тема>/
icewm --restart &
```

### Проверено

- antiX 26.1 (x64), IceWM, тема `macOS-antiX`, кнопки 20×28 → 20×56.
